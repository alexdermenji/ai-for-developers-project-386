# Первая фича: главная страница

Согласовано с пользователем в интервью grill-with-docs.

## Назначение

Объяснить посетителю назначение сервиса и привести его на страницу записи на звонок. Владелец календаря один, регистрация посетителя не требуется. Термины определены в `GLOSSARY.md`, границы сервиса — в `docs/adr/0001-single-calendar-without-auth.md`.

## Главная страница `/`

- Заголовок: «Календарь звонков».
- Описание: «Выберите удобное время для 30-минутного звонка».
- Основное действие: «Записаться на звонок», переход на `/book`.

## Страница записи `/book`

- Заголовок: «Запись на звонок».
- Временный текст: «Выбор времени скоро появится».
- Ссылка «На главную», переход на `/`.
- Прямое открытие и обновление `/book` должны работать.

## Оформление и границы

Русский язык, светлая тема Mantine, удобное отображение на телефоне. На этом этапе нет дополнительных блоков, анимаций, каталога типов встреч, формы бронирования и вымышленных свободных слотов. Реальное бронирование реализуется на следующих шагах курса.

## Проверка результата

- На `/` отображаются согласованные заголовок, описание и основное действие.
- Нажатие «Записаться на звонок» открывает `/book` с согласованным содержимым.
- Нажатие «На главную» возвращает на `/`.
- Прямое открытие и обновление `/book` сохраняют страницу записи.
- На узком экране содержание читается, действие доступно, горизонтальная прокрутка не требуется.
- Тесты покрывают содержание главной, переход к записи и возврат.
- Линтер, тесты и сборка проходят; workflow CI в GitHub Actions зелёный.
