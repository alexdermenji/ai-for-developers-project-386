# Единый календарь без авторизации

Для учебного сервиса используем один календарь одного владельца; посетители записываются на 30-минутные звонки без регистрации. Вместо поддержки нескольких владельцев и личных кабинетов сосредоточимся на выборе свободного времени и записи, как требует проект Хекслета. Авторизации нет и для владельца: при добавлении управления календарём нельзя считать его страницу защищённой; использование с реальными данными потребует пересмотра этого решения.
