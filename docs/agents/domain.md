# Документы предметной области

Используем single-context:
- GLOSSARY.md в корне — общий словарь терминов.
- docs/adr/ — архитектурные решения.

Перед изучением кода читай словарь и относящиеся к задаче ADR.
Если документов ещё нет, продолжай работу без предупреждений.
domain-modeling создаёт их по мере согласования терминов и решений.

Используй термины из словаря в коде, тестах и задачах.
Противоречия с существующими ADR указывай явно.
