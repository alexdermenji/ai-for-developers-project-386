# Метки задач

Имена ролей совпадают с метками GitHub:

- needs-triage — требуется разбор.
- needs-info — требуется дополнительная информация.
- ready-for-agent — задача готова для агента.
- ready-for-human — требуется выполнение человеком.
- wontfix — задача не будет выполняться.

Скиллы должны использовать эти имена меток.
